\section*{Abstract}


The rapid spread of fake news through social media has created a need for detection methods that can analyse both textual and visual evidence. Many online posts contain short text together with images, and the trustworthiness of each modality can vary across samples. Fixed multimodal fusion methods combine image and text predictions using predefined rules, but they do not explicitly adapt modality contribution when confidence, quality, or disagreement changes. This creates a research gap for explainable sample-level adaptive image-text fusion in fake news detection.


This research proposes an explainable deep learning framework for fake news detection using reinforcement learning-based adaptive image-text fusion. The framework trains separate image and text classifiers using a ResNet-based image branch and a DistilBERT-based text branch. It then constructs a reliability-aware state representation containing modality probabilities, confidence values, quality indicators, disagreement, confidence difference, and quality difference. A reinforcement learning fusion controller selects an action corresponding to image and text weights for each sample. The final prediction is produced by combining modality probabilities according to the selected action. The framework also provides explanation outputs through Grad-CAM image heatmaps, token-level text saliency, selected fusion actions, and modality weights.


The framework was evaluated on a Fakeddit-derived multimodal subset containing 26,471 available image-text samples across training, validation, and test splits. The image-only and text-only branches achieved test macro F1 scores of 0.7769 and 0.8388, respectively. The main adaptive fusion run achieved a test macro F1 of 0.8676, and validation-selected threshold tuning improved this to 0.8685. The result was competitive with strong fixed-fusion baselines while adding sample-level interpretability through adaptive modality weights and explanation artifacts. The findings indicate that reliability-aware adaptive fusion is a useful direction for explainable multimodal fake news detection.


Keywords: Fake news detection; multimodal learning; reinforcement learning; adaptive fusion; explainable AI.
